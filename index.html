📖 Panduan Integrasi Google Sheet (Akun Guru, Bank Soal & Rekap)
  1. Buka Google Sheets baru, lalu klik menu Ekstensi (Extensions) → Apps Script.
  2. Hapus seluruh kode bawaan di editor Apps Script, lalu tempel kode lengkap di bawah ini dan klik Run (▶) pada fungsi setupAwalALO untuk membuat 3 tab otomatis.
  3. Klik Terapkan (Deploy) → Deployment baru (New deployment) → Pilih jenis Aplikasi web (Web app).
  4. Pada Yang memiliki akses (Who has access) pilih Siapa saja (Anyone), lalu klik Terapkan dan salin URL Web App-nya.
